## Data Flow

1. **User Browses Surfaces:**
   - User navigates through [`CollectionsGallery`](file:///Users/rohitreddy/Library/Mobile%20Documents/com~apple~CloudDocs/Downloads/tiles%20project/src/components/CollectionsGallery.tsx).
   - Selecting a filter pill updates local state `selectedCategory` without page reload.
   - Clicking a tile product passes the `TileProduct` model to `CollectionModal` via state in `CollectionsGallery`.
2. **Product Specification Inspection:**
   - [`CollectionModal`](file:///Users/rohitreddy/Library/Mobile%20Documents/com~apple~CloudDocs/Downloads/tiles%20project/src/components/CollectionModal.tsx) renders verified dimensions, finish, and material.
   - User clicks *"Enquire Availability on WhatsApp"*, which URL-encodes the product name, dimensions, and finish directly into `https://wa.me/919908686789?text=...`.
3. **General Showroom Quote Request:**
   - User clicks *"Enquire Now"* or *"Request Showroom Quote"* anywhere on the site.
   - Handler `handleOpenEnquiry()` in [`App.tsx`](file:///Users/rohitreddy/Library/Mobile%20Documents/com~apple~CloudDocs/Downloads/tiles%20project/src/App.tsx) opens [`EnquiryModal`](file:///Users/rohitreddy/Library/Mobile%20Documents/com~apple~CloudDocs/Downloads/tiles%20project/src/components/EnquiryModal.tsx).
   - User submits form → client-side validation runs → pre-formatted WhatsApp string dispatched to Tile World staff + immediate phone fallback displayed.
4. **Gallery Lightbox Exploration:**
   - User clicks any architectural showcase photo.
   - [`ShowcaseGallery`](file:///Users/rohitreddy/Library/Mobile%20Documents/com~apple~CloudDocs/Downloads/tiles%20project/src/components/ShowcaseGallery.tsx) sets `lightboxIndex`.
   - [`Lightbox`](file:///Users/rohitreddy/Library/Mobile%20Documents/com~apple~CloudDocs/Downloads/tiles%20project/src/components/Lightbox.tsx) renders full-screen with active keyboard event listeners (`Escape`, `ArrowLeft`, `ArrowRight`).
